## Installation — Ubuntu 24.04 (Noble)

```
┌─────────────────────────────────────────────────────────────┐
│              ROS2 JAZZY INSTALLATION STEPS                  │
│                                                             │
│  1. Set locale                                              │
│  2. Add ROS2 apt repository                                 │
│  3. Install ROS2                                            │
│  4. Source setup in .bashrc                                 │
│  5. Install colcon build tool                               │
└─────────────────────────────────────────────────────────────┘
```

### Step 1 — Set locale
```bash
sudo apt update && sudo apt install -y locales
sudo locale-gen en_US en_US.UTF-8
sudo update-locale LC_ALL=en_US.UTF-8 LANG=en_US.UTF-8
export LANG=en_US.UTF-8
```

### Step 2 — Add ROS2 apt repository
```bash
sudo apt install -y software-properties-common curl

sudo curl -sSL https://raw.githubusercontent.com/ros/rosdistro/master/ros.key \
  -o /usr/share/keyrings/ros-archive-keyring.gpg

echo "deb [arch=$(dpkg --print-architecture) signed-by=/usr/share/keyrings/ros-archive-keyring.gpg] \
  http://packages.ros.org/ros2/ubuntu $(. /etc/os-release && echo $UBUNTU_CODENAME) main" \
  | sudo tee /etc/apt/sources.list.d/ros2.list > /dev/null
```

### Step 3 — Install ROS2 Jazzy
```bash
sudo apt update
sudo apt upgrade -y
sudo apt install -y ros-jazzy-desktop
```

> `ros-jazzy-desktop` includes ROS2 core, rclpy, rviz2, and demo nodes.
> Use `ros-jazzy-ros-base` for a minimal install (no GUI tools).

### Step 4 — Source ROS2 in every terminal
Add to `~/.bashrc` so it loads automatically:
```bash
echo "source /opt/ros/jazzy/setup.bash" >> ~/.bashrc
source ~/.bashrc
```

Verify installation:
```bash
ros2 --help        # should print ros2 commands
ros2 doctor        # checks your environment for issues
```

### Step 5 — Install colcon (build tool)
```bash
sudo apt install -y python3-colcon-common-extensions
```

### Step 6 — Install additional useful tools
```bash
# rosdep — auto-installs dependencies
sudo apt install -y python3-rosdep
sudo rosdep init
rosdep update
```

### WSL2 specific note
If you are on WSL2 and see display/GUI errors, set this in `~/.bashrc`:
```bash
export DISPLAY=:0
```

## Setup

### Installation
ROS2 Jazzy is installed at `/opt/ros/jazzy`.

Add to `~/.bashrc` so ROS2 is available in every terminal:
```bash
source /opt/ros/jazzy/setup.bash
```

### Workspace Setup
```
~/ros2_ws/
├── src/          ← your packages go here
├── build/        ← auto-generated by colcon
├── install/      ← auto-generated, source this
└── log/          ← build logs
```

```bash
mkdir -p ~/ros2_ws/src
cd ~/ros2_ws
colcon build
source ~/ros2_ws/install/setup.bash
```

> **Rule:** Every time you open a new terminal, run:
> `source ~/ros2_ws/install/setup.bash`

## Concept 1 — Topics (Publisher / Subscriber)

```
┌─────────────────────────────────────────────────────┐
│                                                     │
│   ┌───────────┐         ┌──────────────────────┐   │
│   │ Publisher │──────→  │    /topic_name       │   │
│   │   node    │  data   │   (the channel)      │   │
│   └───────────┘         └──────────────────────┘   │
│                                   │                 │
│                          data ↓   │ data ↓          │
│                                   │                 │
│                    ┌──────────────┴──────────────┐  │
│                    │        Subscriber(s)         │  │
│                    │   (can be many listeners)    │  │
│                    └─────────────────────────────┘  │
│                                                     │
│  Use for: continuous streaming data (sensors, etc)  │
└─────────────────────────────────────────────────────┘
```

### Verify with demo nodes
```bash
ros2 run demo_nodes_py talker     # Terminal 1
ros2 run demo_nodes_py listener   # Terminal 2
```

### Create your package
```bash
cd ~/ros2_ws/src

```

### Package structure created
```
my_robot/
├── my_robot/         ← Python code goes here
│   └── __init__.py
├── resource/
├── test/
├── package.xml       ← dependencies
├── setup.cfg
└── setup.py          ← register your nodes here
```

### Publisher node — `my_robot/my_robot/talker.py`
```python
import rclpy
from rclpy.node import Node
from std_msgs.msg import String

class Talker(Node):
    def __init__(self):
        super().__init__('my_talker')
        self.publisher = self.create_publisher(String, 'my_chatter', 10)
        self.timer = self.create_timer(1.0, self.publish_message)
        self.count = 0

    def publish_message(self):
        msg = String()
        msg.data = f'Hello from my node: {self.count}'
        self.publisher.publish(msg)
        self.get_logger().info(f'Publishing: {msg.data}')
        self.count += 1

def main(args=None):
    rclpy.init(args=args)
    node = Talker()
    rclpy.spin(node)
    node.destroy_node()
    rclpy.shutdown()
```

### Subscriber node — `my_robot/my_robot/listener.py`
```python
import rclpy
from rclpy.node import Node
from std_msgs.msg import String

class Listener(Node):
    def __init__(self):
        super().__init__('my_listener')
        self.subscription = self.create_subscription(
            String, 'my_chatter', self.callback, 10
        )

    def callback(self, msg):
        self.get_logger().info(f'I heard: {msg.data}')

def main(args=None):
    rclpy.init(args=args)
    node = Listener()
    rclpy.spin(node)
    node.destroy_node()
    rclpy.shutdown()
```

### Register in `setup.py` → `entry_points`
```python
entry_points={
    'console_scripts': [
        'talker = my_robot.talker:main',
        'listener = my_robot.listener:main',
    ],
},
```

### Build and run
```bash
cd ~/ros2_ws
colcon build --packages-select my_robot
source ~/ros2_ws/install/setup.bash
ros2 run my_robot talker      # Terminal 1
ros2 run my_robot listener    # Terminal 2
```

## Concept 2 — Services (Request / Reply)

```
┌─────────────────────────────────────────────────────┐
│                                                     │
│   ┌────────────┐   request    ┌──────────────────┐  │
│   │   Client   │ ──────────→  │     Server       │  │
│   │    node    │              │      node        │  │
│   │            │ ←──────────  │                  │  │
│   └────────────┘   response   └──────────────────┘  │
│                                                     │
│  Use for: one-time actions (add numbers, take photo, │
│           trigger something, ask for a status)      │
└─────────────────────────────────────────────────────┘
```

### Server node — `my_robot/my_robot/service_server.py`
```python
import rclpy
from rclpy.node import Node
from example_interfaces.srv import AddTwoInts

class AddTwoIntsServer(Node):
    def __init__(self):
        super().__init__('add_two_ints_server')
        self.srv = self.create_service(AddTwoInts, 'add_two_ints', self.handle_request)
        self.get_logger().info('Server ready, waiting for requests...')

    def handle_request(self, request, response):
        response.sum = request.a + request.b
        self.get_logger().info(f'Request: {request.a} + {request.b} = {response.sum}')
        return response

def main(args=None):
    rclpy.init(args=args)
    node = AddTwoIntsServer()
    rclpy.spin(node)
    node.destroy_node()
    rclpy.shutdown()
```

### Client node — `my_robot/my_robot/service_client.py`
Takes two numbers as command line arguments.
```python
import sys
import rclpy
from rclpy.node import Node
from example_interfaces.srv import AddTwoInts

class AddTwoIntsClient(Node):
    def __init__(self, a, b):
        super().__init__('add_two_ints_client')
        self.client = self.create_client(AddTwoInts, 'add_two_ints')

        while not self.client.wait_for_service(timeout_sec=1.0):
            self.get_logger().info('Waiting for server...')

        self.send_request(a, b)

    def send_request(self, a, b):
        request = AddTwoInts.Request()
        request.a = a
        request.b = b
        future = self.client.call_async(request)
        rclpy.spin_until_future_complete(self, future)
        result = future.result()
        self.get_logger().info(f'Result: {a} + {b} = {result.sum}')

def main(args=None):
    if len(sys.argv) != 3:
        print('Usage: ros2 run my_robot service_client <num1> <num2>')
        return
    a = int(sys.argv[1])
    b = int(sys.argv[2])
    rclpy.init(args=args)
    node = AddTwoIntsClient(a, b)
    node.destroy_node()
    rclpy.shutdown()
```

### Register in `setup.py`
```python
'service_server = my_robot.service_server:main',
'service_client = my_robot.service_client:main',
```

### Run
```bash
ros2 run my_robot service_server          # Terminal 1
ros2 run my_robot service_client 10 25   # Terminal 2
```

## Concept 3 — Parameters

```
┌─────────────────────────────────────────────────────┐
│                                                     │
│   Without parameters:                               │
│   ┌──────────────────────────────────────────────┐  │
│   │  self.create_timer(1.0, ...)  ← hardcoded    │  │
│   └──────────────────────────────────────────────┘  │
│                                                     │
│   With parameters:                                  │
│   ┌──────────────────────────────────────────────┐  │
│   │  self.declare_parameter('publish_rate', 1.0) │  │
│   │  rate = self.get_parameter('publish_rate')   │  │
│   │  self.create_timer(rate, ...)   ← flexible   │  │
│   └──────────────────────────────────────────────┘  │
│                    ↓                                │
│   ros2 run my_robot param_node \                    │
│     --ros-args -p publish_rate:=0.5                 │
│                                                     │
└─────────────────────────────────────────────────────┘
```

### Parameterized node — `my_robot/my_robot/param_node.py`
```python
import rclpy
from rclpy.node import Node
from std_msgs.msg import String

class ParamNode(Node):
    def __init__(self):
        super().__init__('param_node')

        self.declare_parameter('publish_rate', 1.0)
        self.declare_parameter('message', 'Hello from param node')

        rate = self.get_parameter('publish_rate').value
        self.msg_text = self.get_parameter('message').value

        self.publisher = self.create_publisher(String, 'my_chatter', 10)
        self.timer = self.create_timer(rate, self.publish_message)
        self.get_logger().info(f'Publishing every {rate}s: "{self.msg_text}"')

    def publish_message(self):
        msg = String()
        msg.data = self.msg_text
        self.publisher.publish(msg)

def main(args=None):
    rclpy.init(args=args)
    node = ParamNode()
    rclpy.spin(node)
    node.destroy_node()
    rclpy.shutdown()
```

### Register in `setup.py`
```python
'param_node = my_robot.param_node:main',
```

### Run
```bash
# Default values
ros2 run my_robot param_node

# Custom values at runtime
ros2 run my_robot param_node --ros-args -p publish_rate:=0.5 -p message:="ROS2 params work!"
```

## Concept 5 — Custom Messages

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  Built-in types:   String, Bool, Int32, Float64 ...        │
│                                                             │
│  Custom type:      YOUR OWN structure                       │
│  ┌──────────────────────────────────────────────────────┐   │
│  │  SensorReading.msg                                   │   │
│  │  ─────────────────                                   │   │
│  │  float64 temperature                                 │   │
│  │  float64 humidity                                    │   │
│  └──────────────────────────────────────────────────────┘   │
│         ↓  colcon build generates Python class              │
│  from my_robot_msgs.msg import SensorReading                │
│                                                             │
│  ⚠️  IMPORTANT: Custom msgs need their own ament_cmake      │
│     package — they CANNOT live in a Python package          │
└─────────────────────────────────────────────────────────────┘
```

### Workspace structure with messages package
```
~/ros2_ws/src/
├── my_robot/              ← ament_python  (your nodes)
│   ├── my_robot/
│   │   ├── talker.py
│   │   ├── listener.py
│   │   └── sensor_publisher.py
│   ├── launch/
│   ├── setup.py
│   └── package.xml
│
└── my_robot_msgs/         ← ament_cmake  (your messages)
    ├── msg/
    │   └── SensorReading.msg
    ├── CMakeLists.txt
    └── package.xml
```

### Step 1 — Create messages package
```bash
cd ~/ros2_ws/src
ros2 pkg create --build-type ament_cmake my_robot_msgs
mkdir ~/ros2_ws/src/my_robot_msgs/msg
```

### Step 2 — Define the message — `my_robot_msgs/msg/SensorReading.msg`
```
float64 temperature
float64 humidity
```

### Step 3 — `my_robot_msgs/package.xml`
```xml
<?xml version="1.0"?>
<package format="3">
  <name>my_robot_msgs</name>
  <version>0.0.0</version>
  <description>Custom messages for my_robot</description>
  <maintainer email="parvez.sd@viavisolution.com">parvez</maintainer>
  <license>MIT</license>

  <buildtool_depend>ament_cmake</buildtool_depend>
  <buildtool_depend>rosidl_default_generators</buildtool_depend>
  <exec_depend>rosidl_default_runtime</exec_depend>
  <member_of_group>rosidl_interface_packages</member_of_group>

  <export>
    <build_type>ament_cmake</build_type>
  </export>
</package>
```

### Step 4 — `my_robot_msgs/CMakeLists.txt`
```cmake
cmake_minimum_required(VERSION 3.8)
project(my_robot_msgs)

find_package(ament_cmake REQUIRED)
find_package(rosidl_default_generators REQUIRED)

rosidl_generate_interfaces(${PROJECT_NAME}
  "msg/SensorReading.msg"
)

ament_package()
```

### Step 5 — Add dependency in `my_robot/package.xml`
```xml
<depend>my_robot_msgs</depend>
```

### Step 6 — Build messages first, then your package
```bash
cd ~/ros2_ws
colcon build --packages-select my_robot_msgs
source ~/ros2_ws/install/setup.bash

# Verify it worked
ros2 interface show my_robot_msgs/msg/SensorReading

colcon build --packages-select my_robot
source ~/ros2_ws/install/setup.bash
```

### Using the custom message in a node — `my_robot/my_robot/sensor_publisher.py`
```python
import rclpy
from rclpy.node import Node
from my_robot_msgs.msg import SensorReading

class SensorPublisher(Node):
    def __init__(self):
        super().__init__('sensor_publisher')
        self.publisher = self.create_publisher(SensorReading, 'sensor_data', 10)
        self.timer = self.create_timer(1.0, self.publish_reading)
        self.count = 0

    def publish_reading(self):
        msg = SensorReading()
        msg.temperature = 25.0 + self.count * 0.1
        msg.humidity = 60.0 + self.count * 0.5
        self.publisher.publish(msg)
        self.get_logger().info(f'Published: temp={msg.temperature:.1f} humidity={msg.humidity:.1f}')
        self.count += 1

def main(args=None):
    rclpy.init(args=args)
    node = SensorPublisher()
    rclpy.spin(node)
    node.destroy_node()
    rclpy.shutdown()
```

## Final `setup.py` Reference

```python
import os
from glob import glob
from setuptools import find_packages, setup

package_name = 'my_robot'

setup(
    name=package_name,
    version='0.0.0',
    packages=find_packages(exclude=['test']),
    data_files=[
        ('share/ament_index/resource_index/packages',
            ['resource/' + package_name]),
        ('share/' + package_name, ['package.xml']),
        (os.path.join('share', package_name, 'launch'), glob('launch/*.py')),
    ],
    install_requires=['setuptools'],
    zip_safe=True,
    maintainer='parvez',
    maintainer_email='parvez.sd@viavisolution.com',
    description='ROS2 learning package',
    license='MIT',
    extras_require={'test': ['pytest']},
    entry_points={
        'console_scripts': [
            'talker = my_robot.talker:main',
            'listener = my_robot.listener:main',
            'service_server = my_robot.service_server:main',
            'service_client = my_robot.service_client:main',
            'param_node = my_robot.param_node:main',
            'sensor_publisher = my_robot.sensor_publisher:main',
        ],
    },
)
```

## Quick Reference Cheat Sheet

```
┌─────────────────────────────────────────────────────────────┐
│                    BUILD CYCLE                              │
│                                                             │
│  1. write code                                              │
│  2. cd ~/ros2_ws                                            │
│  3. colcon build --packages-select <package>                │
│  4. source ~/ros2_ws/install/setup.bash                     │
│  5. ros2 run <package> <node>                               │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│                   USEFUL COMMANDS                           │
│                                                             │
│  ros2 topic list              list all active topics        │
│  ros2 topic echo /topic       print messages on a topic     │
│  ros2 node list               list all running nodes        │
│  ros2 service list            list all active services      │
│  ros2 interface show <type>   inspect a message/service     │
│  ros2 param list              list parameters of nodes      │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│              TOPICS vs SERVICES — WHEN TO USE               │
│                                                             │
│  TOPIC    → sensor data, camera feed, ongoing streams       │
│  SERVICE  → trigger action, ask for a value, one-shot work  │
└─────────────────────────────────────────────────────────────┘
```
